Battery-voltage auto start/stop (this machine)

Starts the generator when the house battery voltage sags too low and stops it once it's charged back up — using the real house volts the genset now reports (grey sense lead wired to the house bank). Runs on this machine (needs the server up) and is the sole auto-start authority. Ignores quiet hours by design (protecting the bank wins).

⚠ Genset built-in auto — do not enable

Don't turn this on. On this unit, enabling the genset's own auto mode immediately cranks the engine with no trigger condition (confirmed bug — see the Activity log). This app never uses it and sends auto-OFF on every connect to keep it disarmed. The fields below are kept for diagnostics only — use App automation (Control tab) for hands-off start/stop.

During quiet time the generator won't auto-start. Times are the genset's local time.

Cold start (heater) — this machine

Starts the generator when it gets cold so a heater can run off generator power instead of draining the batteries. Runs on this machine — needs the server up.
